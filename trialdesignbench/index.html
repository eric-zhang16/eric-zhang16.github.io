What it is

  • A benchmark for evaluating whether AI agents can reproduce or design clinical trial statistical designs
  • Each case = one trial × one benchmark task
  • Closed-book: the model sees only the protocol/SAP, not prior knowledge of the trial

A case = 3 inputs

  1. Shared statistician-role system prompt (same for every case)
  2. Question blocks (extraction vs. derivation) for the trial
  3. The trial's protocol/SAP source document

The held-out answer key never enters a run's context

Question types

TypeAsk
ExtractionReport a value found directly in the document
DerivationIdentify inputs, calculate, and explain method (verified by re-running the calculation)

Grading

  • Rubric criteria per prompt, weighted by importance
  • Concept match required, not keyword match
  • Independent verification pass before a grade is finalized
